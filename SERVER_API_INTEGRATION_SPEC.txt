================================================================================
  REMOTE CARE MONITOR — 5-MINUTE SERVER POST API SPECIFICATION
  For Custom Server & Backend Integration (Raspberry Pi / Node.js / Python / Go)
================================================================================

This document specifies the exact JSON data structures sent by the Remote Care 
desktop client application to your server every 5 minutes.

You can use these specifications to implement your receiving API endpoint in any
backend framework (Node.js/Express, Python/Flask/FastAPI, Go, PHP, etc.).

There are two primary POST endpoints sent by the client:
  1. POST /api/history (or /api/diagnostic/history) -> Logged history of monitor status changes (Every 5 min)
  2. POST /api/sync    (or /api/diagnostic/sync)    -> System telemetry, hardware stats & heartbeat (Every 5 min)

--------------------------------------------------------------------------------
PART 1: POST /api/history (LOGGED HISTORY OF RESULT CHANGES)
--------------------------------------------------------------------------------

Trigger: Dispatched periodically every 5 minutes (configurable in Client Settings).
Purpose: Used by remote terminals to report monitor state changes (e.g. healthy -> down, or down -> healthy).
Deduplication Rule: Automatically skips saving duplicate records if the status remains continuously identical.
                    Saves to DB only on state changes or initial entry.

HTTP Request Details:
  - Method:       POST
  - URL Path:     /api/history (or /api/diagnostic/history)
  - Headers:
      Content-Type: application/json
      x-api-key: YOUR_DIAGNOSTIC_SECRET_KEY (or Authorization: Bearer <TOKEN>)
  - User-Agent:   RemoteCareMonitor-HistorySync/2.0

--------------------------------------------------------------------------------
FIELD DEFINITIONS FOR /api/history:
--------------------------------------------------------------------------------
Top-Level Fields:
  - version         (String)  : Protocol version, currently "2.0".
  - dispatchedAt    (String)  : ISO 8601 UTC timestamp when client sent the payload.
  - clientHostname  (String)  : OS hostname of the client machine.
  - targetIds       (String/Array) : "all" or array of integer IDs [1, 3] indicating
                                which monitors were selected for transmission.
  - entriesCount    (Integer) : Number of change records included in "history".
  - history         (Array)   : Array of recorded change objects (empty [] if no changes).

History Item Fields:
  - id              (Integer) : Unique auto-increment record ID in client SQLite database.
  - targetId        (String|Integer) : ID of the monitor.
  - targetName      (String)  : Human-readable monitor name configured by user.
  - targetType      (String)  : Type of check ("http", "gateway", "ping", "tcp", "disk", etc.).
  - locationName    (String)  : Device / location name (default: "Main Office" / "Local device").
  - checkedAt       (String)  : ISO 8601 UTC timestamp when check executed.
  - ok              (Boolean) : true if check passed, false if failed.
  - status          (String)  : Monitor state: "healthy", "warning", or "down".
  - message         (String)  : Diagnostic message or error explanation.
  - latencyMs       (Integer|null) : Latency in milliseconds (null if not applicable).
  - details         (Object)  : Additional diagnostic JSON metadata.

================================================================================
PART 2: POST /api/sync (PERIODIC DEVICE TELEMETRY & HEARTBEAT)
================================================================================

Trigger: Dispatched periodically (e.g. every 5 minutes).
Purpose: Dispatched periodically to send full device health, CPU, memory, uptime, and monitor summaries.
Deduplication Rule: Extracts memory/storage metrics. Saves to DB only when storage levels change
                    or cross warning thresholds (usedPercent >= 85%), skipping identical repeated heartbeats.

HTTP Request Details:
  - Method:       POST
  - URL Path:     /api/sync (or /api/diagnostic/sync)
  - Headers:
      Content-Type: application/json
      x-api-key: YOUR_DIAGNOSTIC_SECRET_KEY (or Authorization: Bearer <TOKEN>)
  - User-Agent:   RemoteCareMonitor-CloudSync/2.0

PART 3: MINIMAL PYTHON (FLASK) RECEIVER EXAMPLE WITH DEDUPLICATION
================================================================================

from flask import Flask, request, jsonify

app = Flask(__name__)

# State tracking for deduplication
target_status_map = {}       # key: (client, targetId) -> last_status
last_heartbeat_metrics = {}  # key: hostname -> last_mem_used_percent

AUTH_KEY = "YOUR_DIAGNOSTIC_SECRET_KEY"

def check_auth(req):
    if not AUTH_KEY:
        return True
    api_key = req.headers.get("x-api-key")
    if api_key == AUTH_KEY:
        return True
    auth_header = req.headers.get("Authorization", "")
    if auth_header == f"Bearer {AUTH_KEY}":
        return True
    return False

@app.route('/api/history', methods=['POST'])
@app.route('/api/diagnostic/history', methods=['POST'])
def receive_history():
    if not check_auth(request):
        return jsonify({"error": "Unauthorized"}), 401

    data = request.get_json(silent=True) or {}
    history = data.get('history', [])
    hostname = data.get('clientHostname', 'default')

    inserted = 0
    skipped = 0

    for item in history:
        target_key = f"{hostname}:{item.get('targetId', item.get('targetName'))}"
        prev_status = target_status_map.get(target_key)
        curr_status = item.get('status')

        # Deduplication Rule: Skips identical continuous status
        if prev_status is not None and prev_status == curr_status:
            skipped += 1
        else:
            inserted += 1
            target_status_map[target_key] = curr_status
            # Save state transition to DB here

    return jsonify({
        "success": True,
        "message": f"Ingestion processed successfully. Inserted {inserted} state transition(s), skipped {skipped} duplicate status entry(ies).",
        "inserted_count": inserted,
        "skipped_count": skipped,
        "total_processed": len(history)
    }), 200

@app.route('/api/sync', methods=['POST'])
@app.route('/api/diagnostic/sync', methods=['POST'])
def receive_sync():
    if not check_auth(request):
        return jsonify({"error": "Unauthorized"}), 401

    data = request.get_json(silent=True) or {}
    events = data.get('events', [])

    for ev in events:
        if ev.get('eventType') == 'device.heartbeat' and ev.get('payload'):
            payload = ev['payload']
            host = payload.get('hostname', 'default')
            mem_pct = payload.get('memory', {}).get('usedPercent', 0)

            # Deduplication Rule: Save when levels change or usedPercent >= 85%
            prev_mem = last_heartbeat_metrics.get(host)
            if mem_pct >= 85 or prev_mem is None or prev_mem != mem_pct:
                last_heartbeat_metrics[host] = mem_pct
                # Save heartbeat to DB

    return jsonify({
        "ok": True,
        "received": len(events),
        "timestamp": "2026-10-06T13:00:00.100Z"
    }), 200

@app.route('/health', methods=['GET'])
def health_check():
    return jsonify({"status": "healthy"}), 200

if __name__ == '__main__':
    app.run(host='0.0.0.0', port=3001)

PART 4: MINIMAL NODE.JS (EXPRESS) RECEIVER EXAMPLE WITH DEDUPLICATION
================================================================================

const express = require('express');
const app = express();
app.use(express.json({ limit: '2mb' }));

const targetStatusMap = new Map();
const lastHeartbeatMetrics = new Map();
const AUTH_KEY = 'YOUR_DIAGNOSTIC_SECRET_KEY';

function checkAuth(req) {
  if (!AUTH_KEY) return true;
  return req.headers['x-api-key'] === AUTH_KEY ||
         req.headers['authorization'] === `Bearer ${AUTH_KEY}`;
}

app.post(['/api/history', '/api/diagnostic/history'], (req, res) => {
  if (!checkAuth(req)) return res.status(401).json({ error: 'Unauthorized' });

  const { clientHostname = 'default', history = [] } = req.body;
  let inserted = 0;
  let skipped = 0;

  for (const item of history) {
    const key = `${clientHostname}:${item.targetId || item.targetName}`;
    const prev = targetStatusMap.get(key);
    if (prev !== undefined && prev === item.status) {
      skipped++;
    } else {
      inserted++;
      targetStatusMap.set(key, item.status);
      // Save state transition to DB
    }
  }

  res.status(200).json({
    success: true,
    message: `Ingestion processed successfully. Inserted ${inserted} state transition(s), skipped ${skipped} duplicate status entry(ies).`,
    inserted_count: inserted,
    skipped_count: skipped,
    total_processed: history.length
  });
});

app.post(['/api/sync', '/api/diagnostic/sync'], (req, res) => {
  if (!checkAuth(req)) return res.status(401).json({ error: 'Unauthorized' });

  const events = req.body.events || [];
  for (const ev of events) {
    if (ev.eventType === 'device.heartbeat' && ev.payload) {
      const { hostname = 'default', memory } = ev.payload;
      const memPct = memory?.usedPercent ?? 0;
      const prev = lastHeartbeatMetrics.get(hostname);

      if (memPct >= 85 || prev === undefined || prev !== memPct) {
        lastHeartbeatMetrics.set(hostname, memPct);
        // Save heartbeat to DB
      }
    }
  }

  res.status(200).json({
    ok: true,
    received: events.length,
    timestamp: new Date().toISOString()
  });
});

app.get('/health', (req, res) => {
  res.status(200).json({ status: 'healthy', uptime: process.uptime() });
});

app.listen(3001, '0.0.0.0', () => console.log('Receiver listening on port 3001'));
